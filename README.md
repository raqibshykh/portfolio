# Raqib Ahmed | Web Developer Portfolio

Personal portfolio for Raqib Ahmed, a Web Developer, WordPress Developer, and Front-End Developer based in Sukkur, Sindh, Pakistan.

## Stack

React 18, Vite, React Router, Bootstrap, styled-components, and JSON-driven profile content.

## Run locally

```bash
npm install
npm run dev
```

The editable portfolio content lives in `public/profile/`. Add a real resume URL to `navbar.json` before enabling the Resume link.

## Validate

```bash
npm run test
npm run lint
npm run build
```
